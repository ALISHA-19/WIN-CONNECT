# WIN Connect, Fresh Eyes

A one-page review by Alisha Chaudhari for the **Product Manager** role at WIN (Women Inspiring Network), covering its AI-powered opportunity app, WIN Connect.

**Live page:** https://alisha-19.github.io/WIN-CONNECT/

## What's inside
- **First visit:** what a new woman leader sees, step by step, from the website to the join options, sign-in and the app itself.
- **SWOT in plain words:** where WIN stands today, both inside its control and outside it.
- **The one-line diagnosis:** the product is strong, but visitors can't see it before they sign in.
- **Front door:** the sections I'd add to the public WIN Connect page so people know what's inside before they sign in.
- **Fix list:** small fixes first, bigger ideas after.
- **90-day plan:** listen and learn, open the door, win Davos 2027.
- **One number to steer by:** useful connections made each month.
- **Questions** I'd love to ask the founder.

Built from public information about WIN and WIN Connect. Figures marked as WIN's own are as reported, and the plan is a hypothesis to test with real data.

Plain HTML/CSS/JS in a single `index.html`, no build step.
